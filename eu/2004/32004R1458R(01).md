# Tisková oprava nařízení Komise (ES) č. 1458/2004 ze dne 16. srpna 2004, kterým se mění nařízení Rady (ES) č. 2368/2002, kterým se provádí Kimberleyský systém certifikace pro mezinárodní trh se surovými diamanty ( 
 Úřední věstník Evropské unie L 269 ze dne 17. srpna 2004 
 )

19.8.2004
CS
Úřední věstník Evropské unie
L 271/43
Tisková oprava nařízení Komise (ES) č. 1458/2004 ze dne 16. srpna 2004, kterým se mění nařízení Rady (ES) č. 2368/2002, kterým se provádí Kimberleyský systém certifikace pro mezinárodní trh se surovými diamanty
( 
 Úřední věstník Evropské unie L 269 ze dne 17. srpna 2004 
 )
Na straně 21 nařízení Komise (ES) č. 1458/2004 se 2. bod odůvodnění nahrazuje tímto:
„(2)
V oznámení ze dne 15. června 2004 uvedlo předsednictvo Kimberleyského systému certifikace aktualizovaný seznam členů systému. Aktualizace se týká přidání Norska jako účastníka od 15. června 2004. Příloha II by se proto měla odpovídajícím způsobem změnit,“.
