# Oprava směrnice Evropského parlamentu a Rady 2014/60/EU ze dne 15. května 2014 o navracení kulturních statků neoprávněně vyvezených z území členského státu a o změně nařízení (EU) č. 1024/2012 ( 
 Úřední věstník Evropské unie L 159 ze dne 28. května 2014 
 )

12.6.2015
CS
Úřední věstník Evropské unie
L 147/24
Oprava směrnice Evropského parlamentu a Rady 2014/60/EU ze dne 15. května 2014 o navracení kulturních statků neoprávněně vyvezených z území členského státu a o změně nařízení (EU) č. 1024/2012
( 
 Úřední věstník Evropské unie L 159 ze dne 28. května 2014 
 )
Titulní strana, obsah, a strana 1, název:
místo:
„Směrnice Evropského parlamentu a Rady 2014/60/EU ze dne 15. května 2014 o navracení kulturních statků neoprávněně vyvezených z území členského státu a o změně nařízení (EU) č. 1024/2012 (přepracované znění)“
má být:
„Směrnice Evropského parlamentu a Rady 2014/60/EU ze dne 15. května 2014 o navracení kulturních statků neoprávněně vyvezených z území členského státu a o změně nařízení (EU) č. 1024/2012 (přepracované znění) (Text s významem pro EHP)“;
Strana 6, čl. 17 odst. 1:
místo:
„1. Do 18. prosince 2015 a poté každých pět let …“
má být:
„1. Do 18. prosince 2020 a poté každých pět let …“.
