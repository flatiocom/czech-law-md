# Oprava nařízení Komise v přenesené pravomoci (EU) 2020/217 ze dne 4. října 2019, kterým se pro účely přizpůsobení vědeckotechnickému pokroku mění nařízení Evropského parlamentu a Rady (ES) č. 1272/2008 o klasifikaci, označování a balení látek a směsí a kterým se uvedené nařízení opravuje ( 
 Úřední věstník Evropské unie L 44 ze dne 18. února 2020 
 )

Úřední věstník Evropské unie
CS
Série L
2020/217
23.11.2023
Oprava nařízení Komise v přenesené pravomoci (EU) 2020/217 ze dne 4. října 2019, kterým se pro účely přizpůsobení vědeckotechnickému pokroku mění nařízení Evropského parlamentu a Rady (ES) č. 1272/2008 o klasifikaci, označování a balení látek a směsí a kterým se uvedené nařízení opravuje
( 
 Úřední věstník Evropské unie L 44 ze dne 18. února 2020 
 )
Strana 6, příloha II, kterou se vkládá řádek EUH 211 do části 3 přílohy III nařízení (ES) č. 1272/2008, tabulka, třetí sloupec, řádek týkající se RO:
místo:
„Atenție! Se pot forma picături respirabile periculoase la pulverizare. Nu respirați prin pulverizare sau ceață.”,
má být:
„Atenție! La pulverizare, se pot forma picături respirabile periculoase. Nu inspirați vaporii, ceața sau aerosolii.”
Strana 6, příloha II, kterou se vkládá řádek EUH 211 do části 3 přílohy III nařízení (ES) č. 1272/2008, tabulka, třetí sloupec, řádek týkající se ES:
místo:
“¡Atención! Al rociar pueden formarse gotas respirables peligrosas. No respirar el aerosol.”,
má být:
“¡Atención! Al rociar pueden formarse gotas respirables peligrosas. No respirar el aerosol o la niebla.”
