# Oprava směrnice Rady 2005/19/ES ze dne 17. února 2005, kterou se mění směrnice 90/434/EHS o společném systému zdanění při fúzích, rozděleních, převodech aktiv a výměně akcií týkajících se společností z různých členských států ( 
 Úřední věstník Evropské unie L 58 ze dne 4. března 2005 
 )

21.11.2009
CS
Úřední věstník Evropské unie
L 307/9
Oprava směrnice Rady 2005/19/ES ze dne 17. února 2005, kterou se mění směrnice 90/434/EHS o společném systému zdanění při fúzích, rozděleních, převodech aktiv a výměně akcií týkajících se společností z různých členských států
( 
 Úřední věstník Evropské unie L 58 ze dne 4. března 2005 
 )
Strana 27, příloha, bod y):
místo:
„y)
společnosti podle švédského práva nazvané „aktiebolag“, „försäkringsaktiebolag“, „ekonomiska föreningar“, „sparbanker“, „ömsesidiga försäkringsbolag“;“,
má být:
„y)
společnosti podle švédského práva nazvané „aktiebolag“, „bankaktiebolag“, „försäkringsaktiebolag“, „ekonomiska föreningar“, „sparbanker“, „ömsesidiga försäkringsbolag“;“.
