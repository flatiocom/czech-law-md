 Úřední věstník Evropské unie L 83 ze dne 22. března 2012 
 )

4.7.2018
CS
Úřední věstník Evropské unie
L 167/37

( 
 Úřední věstník Evropské unie L 83 ze dne 22. března 2012 
 )

„
 UHLIČITAN-DIHYDROXID HOŘEČNATÝ

 HYDROGENUHLIČITAN HOŘEČNATÝ 
 “.

„Uhličitan-dihydroxid hořečnatý, hydratovaný“,

„Hydrogenuhličitan hořečnatý, hydratovaný“.
