# Oprava nařízení Komise (ES) č. 2870/2000 ze dne 19. prosince 2000, kterým se stanoví referenční metody Společenství pro analýzu v odvětví lihovin ( 
 Úřední věstník Evropské unie L 333, 29. prosince 2000 
 )

10.8.2023
CS
Úřední věstník Evropské unie
L 200/48
Oprava nařízení Komise (ES) č. 2870/2000 ze dne 19. prosince 2000, kterým se stanoví referenční metody Společenství pro analýzu v odvětví lihovin
( 
 Úřední věstník Evropské unie L 333, 29. prosince 2000 
 )
Strana 37, příloha, kapitola III (Stanovení těkavých látek a methanolu v lihovinách), část III.2 (Stanovení těkavých kongenerů plynovou chromatografií: aldehydy, vyšší alkoholy, ethyl-acetát a methanol), bod 5.4 (Reakční činidla a materiál):
místo:
„2-Methylpropan-1-ol (CAS 78-33-1).“,
má být:
„2-Methylpropan-1-ol (CAS 78-83-1).“.
