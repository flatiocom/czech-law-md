# Oprava nařízení Rady (ES) č. 361/2008 ze dne 14. dubna 2008, kterým se mění nařízení (ES) č. 1234/2007, kterým se stanoví společná organizace zemědělských trhů a zvláštní ustanovení pro některé zemědělské produkty (jednotné nařízení o společné organizaci trhů) ( 
 Úřední věstník Evropské unie L 121 ze dne 7. května 2008 
 )

6.4.2013
CS
Úřední věstník Evropské unie
L 97/4
Oprava nařízení Rady (ES) č. 361/2008 ze dne 14. dubna 2008, kterým se mění nařízení (ES) č. 1234/2007, kterým se stanoví společná organizace zemědělských trhů a zvláštní ustanovení pro některé zemědělské produkty (jednotné nařízení o společné organizaci trhů)
( 
 Úřední věstník Evropské unie L 121 ze dne 7. května 2008 
 )
Strana 8, čl. 21 bod 22 – nový čl. 103c odst. 3 třetí pododstavec nařízení (ES) č. 1234/2007:
místo:
„Pokud se alespoň na 80 % členů organizace producentů vztahuje jeden nebo více stejných agroenvironmentálních závazků podle uvedeného ustanovení, považuje se každý z těchto závazků za environmentální opatření podle prvního pododstavce písm. a).“,
má být:
„Pokud se alespoň na 80 % producentských členů organizace producentů vztahuje jeden nebo více stejných agroenvironmentálních závazků podle uvedeného ustanovení, považuje se každý z těchto závazků za environmentální opatření podle prvního pododstavce písm. a).“
