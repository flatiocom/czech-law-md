# Oprava směrnice Rady ze dne 22. března 1977 o usnadnění účinného výkonu volného pohybu služeb advokátů ( 
 Úřední věstník Evropských společenství L 78 ze dne 26. března 1977, strana 17 
 ) (Zvláštní vydání Úředního věstníku Evropské unie v českém jazyce, kapitola 6, svazek 1, strana 52)

18.8.2006
CS
Úřední věstník Evropské unie
L 226/23
Oprava směrnice Rady ze dne 22. března 1977 o usnadnění účinného výkonu volného pohybu služeb advokátů
( 
 Úřední věstník Evropských společenství L 78 ze dne 26. března 1977, strana 17 
 )
(Zvláštní vydání Úředního věstníku Evropské unie v českém jazyce, kapitola 6, svazek 1, strana 52)
Strana 53, čl. 4 odst. 2:
místo:
„Při výkonu svých činností dodržuje advokát stavovské předpisy hostitelského členského státu …“,
má být:
„Při výkonu těchto činností dodržuje advokát stavovské předpisy hostitelského členského státu …“.
