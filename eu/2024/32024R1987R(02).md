# Oprava nařízení Komise (EU) 2024/1987 ze dne 30. července 2024, kterým se mění nařízení (EU) 2023/915, pokud jde o maximální limity niklu v některých potravinách (

 )

4.2.2026
Oprava nařízení Komise (EU) 2024/1987 ze dne 30. července 2024, kterým se mění nařízení (EU) 2023/915, pokud jde o maximální limity niklu v některých potravinách
( 
 Úřední věstník Evropské unie L, 2024/1987, 31. července 2024 
 )
Strana 6, příloha, kterou se v oddíle 3 „Kovy a jiné prvky“ přílohy I nařízení (EU) 2023/915 doplňuje položka týkající se niklu, bod 3.6.15, druhý sloupec:
místo:
„Dětské příkrmy ( 3 ) kromě výrobků uvedených v bodě 3.6.16.“,
má být:
„Potraviny pro malé děti ( 3 ) kromě výrobků uvedených v bodě 3.6.16.“.
Strana 7, příloha, kterou se v oddíle 3 „Kovy a jiné prvky“ přílohy I nařízení (EU) 2023/915 doplňuje nová položka týkající se niklu, bod 3.6.16, druhý sloupec:
místo:
„Ovocné šťávy ( 9 ), ovocné nektary ( 9 ) a zeleninové šťávy včetně ovocných šťáv ( 9 ), ovocných nektarů ( 9 ) a zeleninových šťáv určených jako dětské příkrmy ( 3 ).“,
má být:
„Ovocné šťávy ( 9 ), ovocné nektary ( 9 ) a zeleninové šťávy včetně ovocných šťáv ( 9 ), ovocných nektarů ( 9 ) a zeleninových šťáv určených jako potraviny pro malé děti ( 3 ).“.
