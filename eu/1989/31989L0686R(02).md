# Oprava směrnice Rady 89/686/EHS ze dne 21. prosince 1989 o sbližování právních předpisů členských států týkajících se osobních ochranných prostředků ( 
 Úřední věstník Evropských společenství L 399 ze dne 30. prosince 1989 
 ) (Zvláštní vydání v češtině, kapitola 13, svazek 10, s. 98)

14.12.2010
CS
Úřední věstník Evropské unie
L 328/36
Oprava směrnice Rady 89/686/EHS ze dne 21. prosince 1989 o sbližování právních předpisů členských států týkajících se osobních ochranných prostředků
( 
 Úřední věstník Evropských společenství L 399 ze dne 30. prosince 1989 
 )
(Zvláštní vydání v češtině, kapitola 13, svazek 10, s. 98)
Strana 105, příloha I, ÚPLNÝ SEZNAM DRUHŮ OOP, KTERÉ NESPADAJÍ DO OBLASTI PŮSOBNOSTI TÉTO SMĚRNICE, bod 3 první odrážka:
místo:
„—
nepříznivým klimatickým podmínkám (pokrývky hlavy, sezónní oděvy, obuv, deštníky atd.),“,
má být:
„—
povětrnostním podmínkám (pokrývky hlavy, sezónní oděvy, obuv, deštníky atd.),“.
